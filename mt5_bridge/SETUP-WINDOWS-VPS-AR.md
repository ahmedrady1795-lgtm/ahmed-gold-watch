# تشغيل القناص مع Exness MT5 على Windows VPS (مرحلة الديمو أولاً)

> هذه تعليمات إعداد فقط. لا تشغّل التداول الحقيقي قبل اختبار التنفيذ والنتائج على حساب تجريبي. لا تضع بيانات Exness أو VPS أو رمز الربط في GitHub أو في محادثات عامة.

## 1) استئجار VPS

- اختر **Windows Server 2019 أو 2022** مع وصول **RDP / Administrator**، وذاكرة **4 GB** و2 vCPU مبدئياً (أو أعلى حسب الاستهلاك).
- اختر اشتراكاً شهرياً في البداية، ثم قارن زمن **Ping** إلى خادم Exness الفعلي قبل اختيار موقع السيرفر.
- راجع السعر النهائي بعد اختيار **Windows**، خصوصاً شروط/رسوم ترخيص Windows؛ بعض المزودين يعرضون ترخيصاً تجريبياً فقط.
- جهّز الحماية الأساسية: كلمة مرور قوية، حساب مزود الخدمة مع 2FA، تحديثات Windows، وإعداد نسخ احتياطي.

## 2) الدخول من الآيفون

1. نزّل **Windows App Mobile** الرسمي من Microsoft على iPhone (كان اسمه Remote Desktop).
2. داخل التطبيق اختر **+ → PC**.
3. أدخل عنوان **IP** الخاص بالسيرفر في **PC Name**.
4. أدخل اسم مستخدم وكلمة مرور Windows VPS التي أرسلها مزود الاستضافة.
5. اختر **Disconnect** عند الانتهاء ولا تستخدم **Sign out / Log off** أثناء تشغيل روبوت التداول.

## 3) تجهيز السيرفر

1. ثبّت MetaTrader 5 إصدار Windows من وسيط Exness، وسجّل الدخول **بحساب Demo** أولاً.
2. تأكد من اسم رمز الذهب الحقيقي داخل MT5 في Market Watch؛ قد يكون `XAUUSD` أو `XAUUSDm` حسب نوع الحساب.
3. ثبّت Python x64 وGit على Windows.
4. افتح PowerShell، ثم نفّذ:

```powershell
git clone --branch railway https://github.com/ahmedrady1795-lgtm/ahmed-gold-watch.git
cd ahmed-gold-watch/mt5_bridge
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

5. افتح ملف `.env` محلياً وعدّل:
   - `SITE_URL=https://ahmed-gold-watch-free.onrender.com`
   - `MT5_BRIDGE_TOKEN=` **نفس الرمز السري** المحدد داخل متغيرات بيئة Render، ولا تكتبه في GitHub.
   - `MT5_SYMBOL=` الاسم الصحيح الظاهر في حساب Exness داخل MT5.
   - اترك `LIVE_TRADING=false` و `SCALP_DEMO_MODE=true` أثناء الاختبار.
6. شغّل `python bridge.py` من مجلد `mt5_bridge` بعد التأكد أن MT5 متصل بحساب التجربة.
7. راقب اتصال `/api/mt5/status`، وفحص حداثة سعر الوسيط والشموع قبل اعتبار الربط ناجحاً.

## 4) ملاحظات ضرورية

- يوجد **مفتاحا تفعيل مستقلان** للتداول الحقيقي: `MT5_AUTOTRADE_ENABLED` على Render و`LIVE_TRADING` على Windows؛ كلاهما يجب أن يظل مقفولاً الآن.
- أنشئ ملفاً فارغاً باسم `KILL_SWITCH` داخل `mt5_bridge` لإيقاف **الصفقات الجديدة** فوراً على السيرفر؛ هذا لا يغلق المراكز المفتوحة تلقائياً.
- أرقام المخاطرة الحالية في `.env.example` **نسب مئوية**؛ لم يتم بعد فرض حد ثابت 7 USD للصفقة / 40 USD لليوم. يجب إضافة واختبار حدود الدولار قبل الانتقال للحقيقي.
- لا تفترض أن البرنامج سيبدأ تلقائياً بعد إعادة تشغيل Windows. جهّز **Task Scheduler** وتشغيل MT5 والـbridge في جلسة Windows المناسبة ثم اختبر إعادة التشغيل بأمان قبل الاعتماد عليه.
- صفقة تجريبية ناجحة لا تثبت ربحية الاستراتيجية. اختبر تحمّل انقطاع السيرفر والاتصال، الانزلاق، فروق الأسعار، والحد الأدنى للّوت لدى Exness.
- لو إعداد Cloudzy يعتمد ترخيص Windows Server تجريبي، تأكد من كيفية الترخيص الدائم وتكلفته قبل الشراء.
