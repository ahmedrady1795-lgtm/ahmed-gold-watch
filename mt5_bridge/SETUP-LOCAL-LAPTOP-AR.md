# تجهيز القناص مع لابتوب Windows في البيت — ديمو أولاً

هذه الخطوات تخص اللابتوب **بدون VPS**. القناص الحالي يعمل كموقع على Render، وبرنامج Bridge يعمل محلياً على لابتوب Windows ويتصل بـMetaTrader 5 من Exness. **التوصيل لا يعني نقل الموقع أو كل محركات التحليل إلى اللابتوب**؛ الموقع يظل خارج جهازك.

> **أمان:** لا ترسل كلمة مرور Exness أو رمز `MT5_BRIDGE_TOKEN` لأي شخص ولا تضفهما إلى GitHub. لا تبدأ بتداول حقيقي. هذه الملفات تجهّز الربط فقط؛ لا يمكن اختبار الاتصال الحقيقي قبل وجود جهاز Windows وMT5 وحساب ديمو، وضبط سر الربط على Render.

## 1. المطلوب على اللابتوب

- Windows 11 مع تحديثاته، ورام 16GB وSSD، وتهوية جيدة.
- إنترنت Wi-Fi ثابت، وشاحن أصلي متصل بالكهرباء.
- **MetaTrader 5 من مصدر Exness الرسمي**، ثم تسجيل الدخول بحساب **Demo**.
- **Python 3.11 أو 3.12 بنسخة 64-bit** من python.org مع تثبيت Python Launcher (`py`).
- Git for Windows أو تحميل ZIP من مستودع GitHub للفرع الصحيح.

## 2. الحصول على نسخة الربط

إن اخترت Git for Windows، افتح PowerShell واكتب:

```powershell
git clone --branch feature/mt5-local-windows-laptop-demo-20261104 https://github.com/ahmedrady1795-lgtm/ahmed-gold-watch.git
```

ثم افتح المجلد `ahmed-gold-watch\mt5_bridge`. البديل: نزّل ZIP للفرع المحدد من GitHub وافك الضغط، ثم افتح نفس المجلد. **هذا فرع تجهيز للمراجعة ولم يُدمج في الفرع الرئيسي أو يُنشر تلقائياً.**

## 3. تثبيت وتجهيز — بالنقر المزدوج

1. شغّل **`setup_laptop.bat`** داخل `mt5_bridge` مرة واحدة. سينشئ بيئة Python معزولة `.venv` ويثبّت المكتبات، ويُنشئ `.env` إن لم يكن موجوداً. لن يمسح إعداداتك القديمة.
2. افتح ملف `.env` محلياً في Notepad، وتأكد من:
   - `SITE_URL=https://ahmed-gold-watch-free.onrender.com`
   - `MT5_BRIDGE_TOKEN=` نفس الرمز السري المحدّد في متغير `MT5_BRIDGE_TOKEN` لخدمة Render. احتفظ به سرياً.
   - `MT5_SYMBOL=` رمز الذهب الظاهر حرفياً في MT5 (قد يكون `XAUUSD` أو `XAUUSDm`).
   - `LIVE_TRADING=false`
   - `SCALP_DEMO_MODE=true`
   - `SEND_ACCOUNT_DETAILS=false` — **لا ترسل رقم الحساب أو الرصيد أو حقوق الملكية** إلى الموقع.
3. افتح منصة MT5 وسجّل دخول **Demo**، واظهر رمز الذهب في Market Watch.
4. شغّل **`start_laptop_demo.bat`**. سيفحص إعدادات الأمان، وأن الحساب ديمو، ثم يبدأ المزامنة والتحليل الافتراضي. لو أي شرط ناقص لن يبدأ.
5. راقب تشغيل الموقع والـBridge. يمكن فحص حالة الربط من `https://ahmed-gold-watch-free.onrender.com/api/mt5/status`، مع الانتباه أن استجابة `connected:true` وحدها لا تثبت نجاح تداول أو دقة التنبؤ.

**الخصوصية:** لا تُرسل كلمات مرور MT5 إلى الموقع في هذا التصميم. عند إغلاق إرسال بيانات الحساب، سيستمر إرسال أسعار الذهب الحية والشموع وبعض إشارات/نتائج الديمو إلى Render عبر HTTPS. الموقع والخادم يستمران جزءاً من النظام. لا تُفعّل `SEND_ACCOUNT_DETAILS=true` إلا لو كنت مدركاً للبيانات التي ستُرسل.

## 4. تشغيل 24 ساعة بدون VPS

- من إعدادات Windows Power، اختر منع **Sleep** عند توصيل الشاحن، ويمكن إطفاء الشاشة تلقائياً. لا تترك اللابتوب مغطى أو على سرير/سطح يمنع التهوية.
- استخدم إعداد غطاء الشاشة بحيث لا يدخل الجهاز Sleep أثناء توصيل الكهرباء **إذا كنت ستغلق الغطاء**، مع مراعاة التهوية. الأسلم ترك الغطاء مفتوحاً في مكان جيد التهوية.
- أوقف إعدادات توفير طاقة Wi-Fi التي تسبب انقطاعه إن ظهرت مشكلة، وراقب استقرار الشبكة.
- برنامج الـBridge وMT5 يحتاجان إلى جلسة Windows نشطة. مجرد قفل شاشة iPhone لا يؤثر عليهما، لكن **إيقاف اللابتوب أو انقطاع Wi-Fi/الكهرباء أو إعادة تشغيل Windows قد يوقف الربط**.
- **لم يتم تفعيل بدء التشغيل التلقائي**. بعد نجاح تجربة الديمو يمكننا إعداد Task Scheduler بعناية بحيث يبدأ MT5 أولاً ثم Bridge بعد تسجيل الدخول، واختبار استعادة الاتصال بعد إعادة التشغيل؛ لا تعتمد على 24/7 حتى نختبر ذلك.
- حافظ على تحديث Windows، جدار الحماية، تشفير الجهاز إن كان متاحاً، ومصادقة GitHub وExness الثنائية. لا تفتح RDP على الإنترنت ولا تشارك كلمة مرور Windows.

## 5. إيقاف القناص وحدود الأمان

- اضغط Ctrl+C في نافذة Bridge لإيقاف البرنامج.
- يمكن إنشاء ملف فارغ باسم `KILL_SWITCH` داخل `mt5_bridge` لمنع **الصفقات الجديدة** عند استخدام محرك التنفيذ؛ لا يغلق أي مركز مفتوح ولا يوقف بالضرورة مزامنة الأسعار.
- في هذا التجهيز يتم رفض التشغيل ما لم يكن الحساب **Demo** و`LIVE_TRADING=false`. تشغيل `start_laptop_demo.bat` لا يرسل أوامر حقيقية، حتى لو كانت الإشارات موجودة.
- لا تفترض أن حدود **7 دولارات للصفقة / 40 دولاراً لليوم** مطبقة؛ الكود الحالي يعتمد بالأساس على حدود نسبية. قبل التفكير في الحقيقي، يجب برمجة الحدود النقدية واختبارها مع السبريد والحد الأدنى للّوت، ومراجعة أدوات الإيقاف.
- قبل الاعتماد على البرنامج اختبر فعلياً: إعادة تشغيل Windows، إغلاق/إعادة فتح MT5، انقطاع Wi-Fi، اختلاف رمز الذهب، فشل الاتصال بـRender، ثم مراجعة نتائج الديمو. **لا توجد ضمانات أرباح أو توقع حركة الشمعة قبل وقوعها.**
