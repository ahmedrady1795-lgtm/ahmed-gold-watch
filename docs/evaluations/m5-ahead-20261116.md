# Pre-candle diagnostic — 2026-11-16

Status: research only; not connected to production UI or execution.
Base: 0f7825b32bb1177a7c58aacec38d8cb7e8628895.

The current momentum/sweep observer was sampled exactly 60 seconds before the NEXT M5 candle, using only earlier closed M1 candles. A frozen protocol records source, evidence timestamp, issuance timestamp, target interval, direction and symmetric one-M1-ATR levels. A duplicate observation cannot overwrite a plan. Five complete M1 bars are required to score; same-minute target/stop touches are ambiguous, missing data is unknown and an opening price outside the frozen bracket is a gap.

This is a diagnostic of the existing predictor, not a newly proven predictive model. The last M1 close substitutes for the live quote with idealized zero publication delay. The reference levels evaluate only the target candle, not execution during the preceding lead minute; there are no transaction costs, fills or spread assumptions. Do not interpret target counts as trading returns.

Input: 300 closed Biquote XAUUSD M1 bars from one day (13:09–18:08 UTC, November 16). An attempted historical date request returned zero bars. No multi-day validation was possible. Chronological 60/40 division is a descriptive split, not an independently sourced out-of-sample test; this date has already been inspected during diagnosis. No parameter search was performed.
